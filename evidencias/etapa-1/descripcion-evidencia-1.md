# Evidencia 1: Informe de las cinco funciones de administración de redes (FCAPS)

De manera **individual**, elaborarás un informe escrito que repase y relacione las cinco
funciones de administración de redes vistas en esta etapa — Configuración, Rendimiento,
Fallas, Contabilidad y Seguridad (el modelo **FCAPS**, introducido en
[`01-administracion-configuracion.md`](../../contenido/etapa-1-funciones-administracion/01-administracion-configuracion.md)) —
usando únicamente lo visto en clase: definiciones, tareas de cada función y los conceptos
o métricas propios de cada una.

Este informe también sirve como repaso para el examen de la etapa: escribirlo de tu propio
puño obliga a repasar las cinco sesiones completas, no solo memorizarlas.

---

## Contenido del informe

El documento debe tener esta estructura, en este orden:

1. **Página 1 — Portada:** tu nombre, grupo y fecha.
2. **Página 2 — Tabla de contenido:** las secciones del desarrollo (una por cada función)
   más la conclusión, cada una con el número de página donde empieza.
3. **Resto de páginas — Desarrollo:** las que necesites según lo que vayas documentando,
   una sección por cada una de las cinco funciones (Configuración,
   Rendimiento, Fallas, Contabilidad, Seguridad). Para cada una:
   1. Definición **en tus propias palabras** (no copiar el texto de las sesiones).
   2. Qué controla o vigila esa función — 2 o 3 elementos clave, en lista o tabla.
   3. El concepto o métrica distintivo de esa función:
      - **Configuración** → línea base (*baseline*) y deriva de configuración
        (*configuration drift*).
      - **Rendimiento** → latencia, jitter, pérdida de paquetes, throughput.
      - **Fallas** → MTBF (tiempo medio entre fallas) y MTTR (tiempo medio de reparación).
      - **Contabilidad** → qué se registra del uso de un usuario y para qué sirve, aunque
        no exista cobro de por medio.
      - **Seguridad** → prevención, detección y respuesta a incidentes, sostenidas por una
        política de seguridad.
   4. Un ejemplo breve **inventado por ti** — distinto al caso narrado en la sesión
      correspondiente — donde esa función sería necesaria.
4. **Conclusión** — un párrafo explicando cómo se relacionan entre sí al menos dos de las
   cinco funciones (FCAPS no son compartimentos aislados; cada sesión ya señala al menos
   una conexión con otra).

- **Plataforma:** NEXUS. Carga tu archivo en la evidencia *"1.3 - Evidencia de aprendizaje
  1: Informe"*.
- Nombra tu archivo de la siguiente forma:

```
EV1_ApellidoNombre.pdf
```

*Ejemplo: `EV1_CruzCielo.pdf`*

- **Fecha de entrega:** Lunes 31 de agosto de 2026.
- **Hora límite:** 7:40 p.m.
- **Tiempo en clase:** 100 minutos, de forma presencial, con equipo e internet disponible
  para redactar y exportar el documento.
